# Baselines

This directory contains third-party and comparison baseline code used for
reproducibility.

## Apple / Nazaret Hybrid ODE Baseline

Path:

```text
ml-heart-rate-models-main/
```

This folder contains the Hybrid ODE baseline released by Apple/Nazaret et al.
for personalized heart-rate modeling. It is included to support a clean FitRec /
Endomondo same-dataset comparison against the DBN model in this repository.

Important files:

|------|---------|
| `ml-heart-rate-models-main/LICENSE` | Original Apple software license |
| `ml-heart-rate-models-main/ACKNOWLEDGEMENTS` | Third-party notices retained from the baseline |
| `ml-heart-rate-models-main/README.md` | Original baseline documentation |
